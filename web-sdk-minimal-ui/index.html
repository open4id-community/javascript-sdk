Open4ID minimal login-UI sample

The same backend as the headless sample, but the whole login UI is the SDK's <open4id-auth> dialog element: sign-in, sign-up, forgot-password, guest, link-email, delete-account, and the Google/Apple popups come free. This page only creates the headless client, bootstraps it, binds both to the element, and reacts to its three events.

Application
Account (needs a signed-in session — the dialog remembers it)

Status

Press “Open login dialog”.
