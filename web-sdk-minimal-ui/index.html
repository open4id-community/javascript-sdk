Open4ID minimal login-UI sample

The same backend as the headless sample, but the whole login UI is the SDK's <open4id-auth> dialog element: sign-in, sign-up, forgot-password, guest, link-email, delete-account, and the Google / GitHub / Facebook / Apple popups come free. This page only creates the headless client, bootstraps it, binds both to the element, and reacts to its three events.

Application
Account (needs a signed-in session — the dialog remembers it)
App-open analytics (optional)

One fire-and-forget appOpen() ping per page load feeds the dashboard's opens/devices counters. The installation id is minted locally and is attribution metadata, not a credential — the server keeps only a salted hash of it.

Delete an account without signing in

For a player who cannot sign in, requestAccountDeletion() emails a single-use 30-minute link. The answer is generic for any well-formed address, so it never reveals whether an account exists. The link points at this origin's /delete-account page, which a real game hosts itself — this sample stops at the request.
